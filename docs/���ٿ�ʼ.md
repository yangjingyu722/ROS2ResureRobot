# 快速开始

## 1. 安装 ROS 2 Humble 和 Gazebo

本工作空间自带国内镜像安装脚本，适用于 Ubuntu 22.04 LTS：

```bash
cd ican_shoot
bash scripts/00_install_ros2_gazebo.sh
```

如果系统已经安装好 ROS 2 Humble 和 Gazebo Classic，可以跳过这一步。

## 2. 安装仿真环境

```bash
bash scripts/01_install_sim_deb.sh
```

仿真环境会安装到：

```text
/opt/ican_shoot_sim
```

## 3. 加载环境

```bash
source scripts/setup_env.sh
```

也可以手动执行：

```bash
source /opt/ros/humble/setup.bash
source /opt/ican_shoot_sim/setup.bash
```

## 4. 启动仿真

带 Gazebo 界面启动：

```bash
bash scripts/run_sim.sh
```

无界面启动：

```bash
bash scripts/run_sim.sh gui:=false
```

底层等价命令：

```bash
ros2 launch ican_shoot_sim sim.launch.py
```

## 5. 检查环境

如需确认环境是否安装正确：

```bash
bash scripts/check_sim_env.sh
```

## 6. 运行示例代码

```bash
colcon build --symlink-install
source install/setup.bash
bash scripts/run_example_mission.sh
```

脚本会打开三个终端标签，分别启动仿真、导航和完整任务程序。请在 `example` 标签页按提示输入 2/3/4 号靶配置；机器人会依次完成 1～4 号点的导航、瞄准和射击，随后返回指挥中心。1 号点使用相机环靶检测，动态靶使用 `/gazebo/model_states` 实时跟踪。

示例源码在 `src/` 目录下，构建产物会生成在当前工作空间的 `build/`、`install/` 和 `log/` 目录中。

示例默认使用调优后的 Nav2 参数和简洁 RViz 配置。RViz 中如果看到大量绿色小箭头，那通常是 AMCL 粒子云显示，不是导航目标。
