# iCAN 射击练习仿真环境接口说明

## 安装

```bash
sudo apt update
sudo apt install ./packages/ican-shoot-sim-practice_0.1.0_amd64.deb
```

## 启动

```bash
source /opt/ros/humble/setup.bash
source /opt/ican_shoot_sim/setup.bash
ros2 launch ican_shoot_sim sim.launch.py
```

## 已提供内容

| 内容 | 说明 |
|------|------|
| Gazebo 世界环境 | 比赛练习场地、任务点、指挥中心、挡板和围墙 |
| 小车模型 | 麦轮小车、相机、雷达、里程计和 TF |
| 靶子模型 | 固定靶、旋转靶、两个平移靶 |
| 靶子运动 | 旋转靶持续旋转，平移靶按预设轨迹运动 |
| 射击服务 | 调用服务后在小车前方生成并发射子弹 |

## 参赛者常用接口

| 名称 | 消息类型 | 方向 | 说明 |
|------|----------|------|------|
| `/cmd_vel` | `geometry_msgs/msg/Twist` | 发布 | 控制小车平面运动 |
| `/odom` | `nav_msgs/msg/Odometry` | 订阅 | 小车里程计 |
| `/scan` | `sensor_msgs/msg/LaserScan` | 订阅 | 二维激光雷达 |
| `/camera/image` | `sensor_msgs/msg/Image` | 订阅 | 前向相机图像 |
| `/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | 订阅 | 相机内参 |
| `/tf` | `tf2_msgs/msg/TFMessage` | 订阅 | 动态坐标变换 |
| `/tf_static` | `tf2_msgs/msg/TFMessage` | 订阅 | 静态坐标变换 |
| `/gazebo/model_states` | `gazebo_msgs/msg/ModelStates` | 订阅 | Gazebo 模型状态 |
| `/shooter/shoot` | `std_srvs/srv/Trigger` | 调用 | 发射一发子弹 |
| `/referee/current_target` | `std_msgs/msg/String` | 发布 | 到达点位并准备射击前，通知裁判系统当前射击点位 |
| `/referee/mission_event` | `std_msgs/msg/String` | 发布 | 成功返航时发布 `returned`，用于独立计算返航分数 |

## `/cmd_vel` 控制说明

`/cmd_vel` 使用 `geometry_msgs/msg/Twist`：

| 字段 | 说明 |
|------|------|
| `linear.x` | 小车前后方向速度 |
| `linear.y` | 小车左右方向速度 |
| `angular.z` | 小车 yaw 角速度 |

示例：

```bash
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2, y: 0.0, z: 0.0}, angular: {z: 0.0}}" -r 10
```

## 传感器参数

| 传感器 | 参数 |
|--------|------|
| 雷达 `/scan` | 360 点，范围 `-pi` 到 `pi`，量程 `0.10m` 到 `12.0m` |
| 相机 `/camera/image` | 分辨率 `800x800`，频率 `30Hz` |

## 裁判点位通知

到达任务点并准备射击前，需要向 `/referee/current_target` 发布当前射击点位。裁判系统收到该消息后，会把后续射击计入对应点位。

| 点位 | 发布内容 |
|------|----------|
| 1 号任务点 | `shoot_1` |
| 2 号任务点 | `shoot_2` |
| 3 号任务点 | `shoot_3` |
| 4 号任务点 | `shoot_4` |

示例：

```bash
ros2 topic pub --once /referee/current_target std_msgs/msg/String "{data: shoot_1}"
```

## 射击服务

调用 `/shooter/shoot`：

```bash
ros2 service call /shooter/shoot std_srvs/srv/Trigger {}
```

也可以调用兼容接口：

```bash
ros2 service call /shooter/fire std_srvs/srv/Trigger {}
```

服务返回的 `message` 字段为本次生成的子弹模型名。子弹默认从 `shout_link` 前方发射，发射高度为 `0.26m`。

## 坐标系

| 坐标系 | 说明 |
|--------|------|
| `odom` | 里程计坐标系 |
| `base_footprint` | 小车底盘平面坐标系 |
| `base_link` | 小车主体坐标系 |
| `laser_link` | 雷达坐标系 |
| `camera_link` | 相机坐标系 |
